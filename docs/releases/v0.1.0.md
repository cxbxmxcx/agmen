The first public release of Agmen: a Windows workspace that runs Claude Code, Codex, Kimi Code and Antigravity CLI sessions as a tree of tabs, where any session can start and direct child sessions of any agent.

## Install

In PowerShell:

```powershell
irm https://github.com/cxbxmxcx/agmen/releases/latest/download/install.ps1 -OutFile "$env:TEMP\agmen-install.ps1"; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\agmen-install.ps1"
```

Or download `Agmen-win-x64.zip` below, extract the whole folder, and run `Agmen.exe`. You need 64-bit Windows 10 or 11 and at least one of the agent CLIs, installed and signed in. .NET doesn't need to be installed.

The exe isn't code-signed, so Windows SmartScreen may warn the first time you run it. `Agmen-win-x64.zip.sha256` holds the zip's SHA-256, and `install.ps1` checks the download against it.

## What's in it

- **Four agent CLIs as tabs**, each the real CLI in Windows Terminal's own terminal control.
- **A session tree.** Any session can start children of any agent, message them, read what they did, and hear back when they finish. A session directs only its own children.
- **A primary session**, run by whichever of the four agents you choose, that keeps an overview of every session and directs its own children.
- **Safe message delivery.** A message is typed into a session only when it's idle and you have nothing half-typed there.
- **Status at a glance**: working, idle, waiting on you; "your turn" and "needs input" badges; color codes and one-line summaries on each card.
- **Restore.** Every tab comes back after a restart or a crash, with its conversation and its place in the tree.
- **Agent settings**: a model, an effort and a permission mode for each agent, applied every time a session starts.
- **Your MCP servers in every agent**, shared from Claude Code's user-level servers.

The [README](https://github.com/cxbxmxcx/agmen#readme) covers each of these, and lists the [known limitations](https://github.com/cxbxmxcx/agmen#known-limitations) of this version.
