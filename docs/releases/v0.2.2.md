This release adds named workspaces, conversation handoffs between agents and a Windows installer. It is the first 0.2 release: 0.2.0 and 0.2.1 were test builds.

## Added

- **Named workspaces.** Use **Workspaces ▾ → New workspace…** or `Agmen.exe --workspace "Research"` to run several session trees at once. Each workspace has its own window, tray icon, tabs, primary session, settings and history. Kimi Code and Antigravity need **Connect** only once for all of them.
- **Continue a conversation with another agent.** Right-click a card and choose **Continue with another agent**. The new agent picks up the conversation in the same tab and keeps its place in the tree.
- **Fork a child with the conversation so far.** **Fork as child with context** gives a new child, of any agent, the conversation up to now, while you keep working in the source tab. A session can do the same with `spawn_child` and `inherit_context: true`.
- **Siblings can talk to each other.** Children of the same top-level tab can find each other with `list_siblings` and send messages with `message_sibling`. You can also share a selected excerpt from the card menu with **Share with sibling…**.
- **A Windows installer.** `Agmen-Setup-x64.exe` installs Agmen for your Windows account, with no administrator rights, adds it to Start and to **Installed apps**, and can start it when you sign in. The zip still works, and `install.ps1` now installs with the setup.

## Fixed

- **Messages to Codex no longer pile up in its prompt.** Codex took the Enter after a long typed message as a new line, so the message waited in its prompt until another was typed after it, and both arrived as one. Agmen now waits longer before Enter for a long message, and presses Enter again if Codex starts no turn.
- **Sessions no longer end at once with "Session Terminated"** when Agmen was started by an installer, a script or another workspace with redirected input or output.

Agmen 0.2.2 includes the Antigravity fixes from 0.1.1.

## Update

Exit Agmen from its tray icon, then download `Agmen-Setup-x64.exe` below and run it. Or run the install command again:

```powershell
irm https://github.com/cxbxmxcx/agmen/releases/latest/download/install.ps1 -OutFile "$env:TEMP\agmen-install.ps1"; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\agmen-install.ps1"
```

Your sessions and settings stay as they are, and your current tabs become the **Default** workspace. If Agmen asks to connect Kimi Code or Antigravity again, choose **Connect**.
