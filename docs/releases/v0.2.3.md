This release fixes messages to Antigravity sessions that waited, sometimes for half an hour, before Antigravity read them.

## Fixed

- **Messages to an Antigravity session no longer wait while it works.** When Antigravity runs a subagent, the subagent reports to Agmen as if it were the session, and the session itself reports a stop while it waits for the subagent. Agmen took either one as the end of the turn and typed queued messages in while Antigravity was still at work, and Antigravity held them until its whole turn was over. Agmen now follows only the session's own conversation and treats it as busy until it is done.
- **An Antigravity session keeps its own conversation.** Agmen no longer switches the conversation it saves for an Antigravity tab to a subagent's, so a restored tab reopens the right one.

Agmen 0.2.3 includes everything in 0.2.2, among it the fix for long messages that stayed unsent in Codex's prompt.

## Update

Exit Agmen from its tray icon, then download `Agmen-Setup-x64.exe` below and run it. Or run the install command again:

```powershell
irm https://github.com/cxbxmxcx/agmen/releases/latest/download/install.ps1 -OutFile "$env:TEMP\agmen-install.ps1"; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\agmen-install.ps1"
```

Your sessions and settings stay as they are. If Agmen asks to connect Kimi Code or Antigravity again, choose **Connect**.
